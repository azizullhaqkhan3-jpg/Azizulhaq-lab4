# Student Course App

A Flutter application for managing student courses with a clean UI and full CRUD functionality.

##  Features

- Home screen with welcome card
- Bottom Navigation Bar (3 Tabs)
- Drawer menu
- Add, Edit, Delete Courses (CRUD)
- Student name input with greeting
- Floating Action Button with SnackBar
- Professional UI design

##  Screens

### Home Tab
Shows a welcome card with styled UI.

### Courses Tab
- Add new courses
- Edit existing courses
- Delete courses
- ListView + CRUD system

### Profile Tab
- Enter student name
- Shows greeting message


##  Technologies Used

- Flutter
- Dart
- Material Design
